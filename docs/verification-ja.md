# 公開版の検証範囲

2026年9月16日、Windows上で公開準備の検証を実施しました。旧環境の作業記録・接続先・個人パスは公開版に含めていません。

## 自動検証

- Node.jsのビルドと31件のテスト：MCP、認証・失効、CSRF、アーカイブ検証、配置状態、データ保持、完全削除、計測、端末登録・再実行。
- 異なるIPと/16サブネット、DNSあり／なしで配布ZIP内の接続設定とMCP URLが一致すること。
- ダウンロード時のサーバー設定がZIPに反映され、リクエストのHostを信用しないこと。
- Windows PowerShellの構文、CIDR判定、設定検証、IPv4自動／IPv6手動DNSの復元（ネットワーク操作を模擬）。
- Ubuntu用シェルスクリプトの構文と設定読み込み（異なるCIDR、不正値、DNS省略、シェル式拒否）。

公開対象だけを抽出したフォルダーでも依存の新規インストール、ビルド、31件のテスト、Windows復元の模擬テストが成功しました。Git管理対象のファイル名・内容の検査、既存トークンとの非表示照合、配布プラグインの形式検証も成功しました。GitHub ActionsではUbuntuとWindowsのNode.js 22で継続検証します。

## 今回未実施の実機検証

- 新規UbuntuでのDocker・Caddy・systemd・dnsmasqの一括導入とOS再起動。
- 実際のLAN内外からのファイアウォール許可・拒否。
- 別のWindows端末でのCA登録、UACによるDNS変更、Codexへの実インストール。
- 稼働アプリの保存・再配置、ボリューム全体のバックアップと復元。

本作業では稼働中サーバー、現在のWindowsのDNS、インストール済みプラグインを変更していません。実機受け入れでは [初期構築](setup-ja.md)、[Windows導入](windows-setup-ja.md)、[運用](operations-ja.md) の順に確認します。
