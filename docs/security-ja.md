# 公開する情報・しない情報

公開対象はサーバーとプラグインのソース、設定例、ガイド、テスト、汎用導入スクリプトです。

`.local-sites`、秘密鍵、端末トークン、実際の.env、ログ、復旧バックアップ、実環境の画像、過去の一度限りの更新・実機検証スクリプト、依存ライブラリ、生成ZIPは公開しません。これらは手元に保持します。.gitignoreだけに頼らず、コミット対象を明示して内容も検査します。

`node scripts/check-publication.mjs` はGit管理対象のファイル名と内容を検査します。秘密鍵のヘッダー、代表的なアクセストークン、個人の絶対パス、禁止ファイルを検出し、値は表示しません。配布ZIPは明示的なファイル一覧から生成し、サーバーURL等の公開設定だけを追加します。公開CAもGitでは配らず、各管理者が検証済み経路で配布します。

パターン検査ですべての秘密を保証することはできないため、公開差分とファイル一覧も確認します。実際の秘密が公開済みと判明した場合は該当資格情報を失効・再発行し、履歴からの除去を別途行います。

登録端末は全アプリを管理できます。一般ユーザー向けの権限分離やアプリの認証は提供しません。TLS検証を無効化せず、DNS変更は内容確認とWindowsの昇格承認を経て実行します。
